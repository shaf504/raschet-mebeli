# mebelshaf — «Рассчитай мебель» (конфигуратор кухни)

Весь проект — **один файл `index.html`** (~3 МБ). Открывается в любом браузере (телефон/ПК), сервер не нужен.
Внутри: разметка, стили, весь JavaScript, каталог материалов и картинки (base64).

Версия: 152 — любая ширина модулей: у шкафа, ящиков, пенала с полками, модуля у угла и углового — 100–3000 мм; у модулей под мойку, духовку, варочную, шкафа с двумя дверцами — своя ширина `P.mods[id].MW` (шаг ±10 или ввод любого числа), у посудомойки — `dwW` (кнопки 450/500/550/600 или своё число); верхние модули — по ширине нижнего. Ранее 151 — счётчик заявок поставщикам: меню «Проект» → «Заявки поставщикам» (`#fly-sup`, `renderSup`); запись при нажатии «МДФ» и при выгрузке «Заказ поставщику» (`supAdd`, `supLogBuy`, повтор за 10 мин не считается), итог по месяцам, отчёт для поставщика (копировать) и CSV; хранится в localStorage «suplog» и в облаке (документ «suplog»). Ранее 150 — кнопка «МДФ» (₽) в левой панели между «Материал» и «Детали» (`#mdfBtn`): сразу открывает WhatsApp компании по фасадам (`MDFPH` = +7 909 587-17-59) с готовым сообщением — фрезеровка со ссылкой-картинкой (`assets/frez/<ключ>.html` + `.jpg`, превью в WhatsApp), цвет, толщина, список деталей с названиями и размерами, итог шт и м² (`mdfList`/`mdfText`). Ранее 148 — заставка с фото кухни (`assets/welcome/kitchen.webp`; телефон: фото + светлая панель снизу, альбом/компьютер: панель слева, фото справа), сведения о последнем сохранённом проекте показываются на заставке (`#welcomeLast`, `asToast`), заставки запуска iOS — то же фото (JPEG). Ранее 147 — новая стартовая заставка в стиле v146 (`assets/welcome/screen.css`: телефон портрет/альбом, планшет, компьютер) и заставки запуска iPhone/iPad с экрана «Домой» (`assets/splash/`, 22 модели × портрет и альбом, теги `apple-touch-startup-image` в <head>). Ранее 146 — полный редизайн: единая дизайн-система (блок «дизайн-система v146» в конце <style>, прежние темы Soft UI и лавандовая удалены): светлый серо-белый фон, белые поверхности, графитовый текст, синий акцент `--accent:#1D4F91`, цвета состояний `--ok/--warn/--err`; шрифты IBM Plex Sans / IBM Plex Mono (JetBrains Mono оставлен для чертежей); один комплект линейных иконок (символы ✕ ⚠ ↗ и т.п. заменены SVG), подписи у иконок раскроя (`CIL`). Логика и расчёты не менялись. Ранее 145 — новое название «Мой расчёт про» и дизайн Soft UI (светлый неоморфизм: мягкие тени, пастельные плитки иконок, вдавливание кнопок, плавное появление панелей; блок стилей «Soft UI» в конце <style>). Ранее 144 — автосохранение (каждое изменение → облако, документ `autosave`, и открытый проект; после вылета открывается последний проект: `asQueue`/`asFlush`/`asRestore`), размеры углового модуля (`P.CRW` ширина, `P.CRD` дверца), меньше видеопамяти на телефоне (`LOWMEM`: чёткость ×2, тень 2048) — против вылетов. Ранее 143 — новый дизайн (светлая лавандовая тема, фиолетовый акцент, крупные цветные иконки), повышенная чёткость 3D и фото для клиента. Ранее: пошаговый выбор из каталога: Корпус (ЛДСП / МДФ / Фанера → бренд → декор), Направляющие (вид → бренд → размер), Ручки (серия → размер → цвет), Петли (вид → бренд → модель).

## Как продолжить работу в другой нейросети (GPT, Gemini и т.п.)
1. Загрузите `index.html` и этот `README.md` в чат.
2. Напишите: «Это мой конфигуратор кухни, вот README. Измени только X, остальное не трогай, верни весь файл целиком».
3. Сохраните полученный файл поверх `index.html` в папке «Расчет мебели».

## Технологии
- three.js r128 (CDN cdnjs) — 3D-сцена; 2D-развёртка — SVG.
- jsPDF (подгружается лениво с CDN) — PDF чертежей, раскроя, заказа поставщику.
- Единицы — миллиметры. Шрифты Montserrat / Onest / JetBrains Mono (Google Fonts).
- Фирменный стиль: фон `#082C3D`, медный градиент, логотип и заставка 3 с.

## Основные структуры данных
- `P` — глобальное состояние проекта (размеры, материалы, ряды модулей).
  - `P.row` — нижний ряд у основной стены, `P.rowL` — ряд у боковой стены (угол), `P.rowI` — остров; `P.isl` — остров вкл/выкл.
  - `P.mods[id]` — индивидуальные настройки модуля; `mergedFor(id)` — итоговые параметры модуля.
  - `P.fMat` — материал фасадов (ЛДСП/МДФ/alu…), `FT()` — толщина фасада.
- `DS`, `DSI` — встроенный каталог (ЛДСП, МДФ, кромка, фурнитура, цены).
- `LASTPARTS` — список деталей `[название, материал, размер, кол-во]`.

## Ключевые функции
- `calcMat()` → `{res, hw, misc, edge}` — расчёт материалов, фурнитуры, кромки, стоимости.
- Раскрой: `packSheets`, `guil()` / `guilSheet()` (гильотинный раскрой с пропилом), `layResolve`, ручные раскладки `m.lay`, формат листа `m.fo`, отрисовка `cutSVG`, PDF `cutPDF`.
- «Технолог» → «Технологические отверстия» (PDF): `thMods()` / `thBase` / `thUp` / `thPen` — присадка каждой детали мм в мм (`thDraw`), крепёж `P.fix` и свой у модуля `P.mods[id].fix` ('conf' евровинт / 'ecc' эксцентрик + шкант), `joint()` — точки крепежа (им же считаются евровинты/эксцентрики в `calcMat`). Кромка корпуса по умолчанию 1 мм (`matSet().ec`), прифуговка `matSet().pre`; в распил = готовый − кромка ≥1 мм + прифуговка.
- `techChecks()` — «Технолог»: проверка правил (зазоры, фасады, холодильник, остров, торцевые боки/цоколь).
- Остров: `islW`, `islOV`, `islSP`, `islNP`, `islOn`, `islBack`, `islCtL`, панель `renderIsl()` / `fly-isl`.
- Подсветка: `LEDZ`, `LEDON`, `ledSegs` (зоны, включая `'isl'`).
- Экспорт: чертежи кухни (PDF), заказ поставщику (PDF), раскрой (PDF/SVG).
- Заказ (`fly-ord`, `renderOrd`, `ordCalc`, `ordPDF`, `ordText`): данные клиента в `P.cl` (сохраняются с проектом), цены за метр и контакты — `KPM` (localStorage `kpm` + облако, документ `kpm`). Метры — авто по модулям (`ordAuto`), себестоимость — материалы из `LASTCOST` + «работа и расходы». В списке проектов — статус, клиент, сумма и фильтр по статусу.
- Проекты сохраняются в хранилище артефакта claude.ai (`claude.use("db")`); при открытии файла вне claude.ai сохранение проектов и скачивание через `downloads` недоступны — остальное работает.

## Боковая панель
Слева: Размер, Фасад, Ручка, Направляющие, Петли, Вид, Корпус, Остров, Столешница, Свет, Материал, Детали.

Пошаговый выбор (`SBT`, `renderSB`, путь в `SBP`): каждая вкладка открывается с первого шага. Выбор направляющих — `P.slCat`, петель — `P.hgCat`; в расчёт попадают через `prjHw()` / `hwLink()`.
Справа: Проект, Заказ, Модули, Угол, Верх, Открыть, 2D, Размеры, Экспорт, Цены, Технолог, Раскрой, Экран.

## Правила работы с кодом
- Менять только то, что просят; не переписывать проект целиком.
- После правки проверить: файл открывается без ошибок в консоли, 3D рисуется, раскрой без ошибок.
