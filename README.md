# mebelshaf — «Рассчитай мебель» (конфигуратор кухни)

Весь проект — **один файл `index.html`** (~3 МБ). Открывается в любом браузере (телефон/ПК), сервер не нужен.
Внутри: разметка, стили, весь JavaScript, каталог материалов и картинки (base64).

Версия: 141 — панель «Заказ»: клиент, статус, цена за погонный метр, доплаты, скидка, предоплата, КП клиенту (PDF / WhatsApp), себестоимость и прибыль.

## Как продолжить работу в другой нейросети (GPT, Gemini и т.п.)
1. Загрузите `index.html` и этот `README.md` в чат.
2. Напишите: «Это мой конфигуратор кухни, вот README. Измени только X, остальное не трогай, верни весь файл целиком».
3. Сохраните полученный файл поверх `index.html` в папке «Расчет мебели».

## Технологии
- three.js r128 (CDN cdnjs) — 3D-сцена; 2D-развёртка — SVG.
- jsPDF (подгружается лениво с CDN) — PDF чертежей, раскроя, заказа поставщику.
- Единицы — миллиметры. Шрифты Montserrat / Onest / JetBrains Mono (Google Fonts).
- Фирменный стиль: фон `#082C3D`, медный градиент, логотип и заставка 3 с.

## Основные структуры данных
- `P` — глобальное состояние проекта (размеры, материалы, ряды модулей).
  - `P.row` — нижний ряд у основной стены, `P.rowL` — ряд у боковой стены (угол), `P.rowI` — остров; `P.isl` — остров вкл/выкл.
  - `P.mods[id]` — индивидуальные настройки модуля; `mergedFor(id)` — итоговые параметры модуля.
  - `P.fMat` — материал фасадов (ЛДСП/МДФ/alu…), `FT()` — толщина фасада.
- `DS`, `DSI` — встроенный каталог (ЛДСП, МДФ, кромка, фурнитура, цены).
- `LASTPARTS` — список деталей `[название, материал, размер, кол-во]`.

## Ключевые функции
- `calcMat()` → `{res, hw, misc, edge}` — расчёт материалов, фурнитуры, кромки, стоимости.
- Раскрой: `packSheets`, `guil()` / `guilSheet()` (гильотинный раскрой с пропилом), `layResolve`, ручные раскладки `m.lay`, формат листа `m.fo`, отрисовка `cutSVG`, PDF `cutPDF`.
- `techChecks()` — «Технолог»: проверка правил (зазоры, фасады, холодильник, остров, торцевые боки/цоколь).
- Остров: `islW`, `islOV`, `islSP`, `islNP`, `islOn`, `islBack`, `islCtL`, панель `renderIsl()` / `fly-isl`.
- Подсветка: `LEDZ`, `LEDON`, `ledSegs` (зоны, включая `'isl'`).
- Экспорт: чертежи кухни (PDF), заказ поставщику (PDF), раскрой (PDF/SVG).
- Заказ (`fly-ord`, `renderOrd`, `ordCalc`, `ordPDF`, `ordText`): данные клиента в `P.cl` (сохраняются с проектом), цены за метр и контакты — `KPM` (localStorage `kpm` + облако, документ `kpm`). Метры — авто по модулям (`ordAuto`), себестоимость — материалы из `LASTCOST` + «работа и расходы». В списке проектов — статус, клиент, сумма и фильтр по статусу.
- Проекты сохраняются в хранилище артефакта claude.ai (`claude.use("db")`); при открытии файла вне claude.ai сохранение проектов и скачивание через `downloads` недоступны — остальное работает.
